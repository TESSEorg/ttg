◆ is_explicit_object_call_op_v

template<typename T , typename CallOpPtr , typename Enabler = void>
constexpr bool ttg::meta::detail::is_explicit_object_call_op_v = false
constexpr

true if CallOpPtr , the type of &T::operator(), is a function pointer obtained from an operator() with an explicit object parameter (C++23 "deducing this", e.g. void operator()(this const T&, int)): its first parameter is the object (of type T or its base), and an object of type T can only be invoked without it. The latter check distinguishes it from a static operator() whose first parameter happens to be the object type.
